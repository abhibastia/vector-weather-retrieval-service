# Databricks Apps installs this at deploy time. Order matters: the CPU-only
# PyTorch index is declared FIRST so `torch` (pulled in transitively by
# sentence-transformers) resolves to the ~200MB CPU wheel instead of the
# ~2.5GB CUDA build. On Databricks Apps compute there is no GPU, and the
# CUDA wheel is large enough to blow the app's build timeout.
--extra-index-url https://download.pytorch.org/whl/cpu
